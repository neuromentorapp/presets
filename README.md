# Пресет NeuroMentor для тех, кто собирает своё приложение сам

Плагин для Claude Code. Превращает помощника в **технаря**, который помогает собрать
продукт: архитектура, выбор стека, сборка экранов, разбор ошибок. Маркетинг, офферы и
тексты он не берёт и честно объясняет почему.

## Установка

Две команды прямо в Claude Code:

```
/plugin marketplace add neuromentorapp/presets
```

```
/plugin install vibe-coder@neuromentor
```

Всё. Ничего скачивать и распаковывать не нужно.

**Сразу после установки включите обновления**, иначе останетесь на первой версии:
`/plugin` → вкладка **Marketplaces** → выбрать `neuromentor` → **Enable auto-update**.

## Что внутри

- **Помощник-технарь.** Говорит понятно: сначала результат, потом устройство. Незнакомые
  слова объясняет один раз в скобках. Ошибку описывает тем, что вы увидите на экране.
- **Окно с вашим приложением поднимается первым**, до всякого кода. Вы говорите словами и
  сразу видите, что изменилось.
- **Первая настройка** задаёт несколько вопросов о вашем проекте и дальше не переспрашивает.
- **Подсказка «что дальше»** — одно ближайшее действие, а не список.
- **Разбор ошибок** без стека вызовов и без «попробуйте перезапустить».

## Чего он не делает и почему

Он не пишет продающие тексты, офферы, посты и рекламу, не придумывает, кому продавать и
по какой цене.

Это не каприз. У него нет вашей Бизнес-ДНК: он не знает вашего клиента, его слов, вашего
предложения и цены. Он сочинит правдоподобное, а вы построите на выдумке и потеряете
недели. Всё это собирается на платформе [NeuroMentor](https://neuromentor.app) из того,
что вам сказали живые люди.

Попросите его об этом — он назовёт причину, скажет, где это делается, и вернётся к
приложению. Настаивать можно, читать нотации он не будет.

## Что понадобится

- Claude Code с подпиской (Pro или выше);
- пять минут на первую настройку.

## Обновления

Приходят сами, если включено автообновление. Вручную:

```
/plugin marketplace update neuromentor
```
